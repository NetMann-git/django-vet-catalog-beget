# Шаг 6 — услуги и цены

Основа: dev_gpt, шаг 5 (origin 37ea3a2). Существующий /services/ и имя
маршрута furniture_services сохранены. Публичная страница больше не
использует services_content.SERVICE_GROUPS и мебельный шаблон.
Старые данные каталога, файлы содержимого и механизмы товаров не удаляются.

Новая обычная Django-модель home.ClinicService хранит услуги отдельно от Product.
Поля: название, уникальное адресное имя, направление, краткое/полное описание,
подготовка, стоимость, пометка «от», пояснение цены, порядок и публикация.
Полное описание/подготовка пока заполняются на будущее: на странице списка
показаны название, направление, краткий текст и стоимость. Отдельная карточка
услуги будет следующим шагом. Новая услуга по умолчанию — черновик.

Добавление в существующей Django-админке, отдельный раздел «Услуги клиники».
Права — стандартные add/change/view/delete модели, без обхода авторизации.
Публичный список, поиск, направления и пагинация видят только опубликованные
записи. Начальные услуги не создаются, цены не выдумываются.

Поиск по названию, краткому описанию и направлению. В SQLite для кириллицы
применён тот же подход casefold + matching IDs, что в существующих фильтрах
каталога; в других СУБД используются icontains и Q. MySQL здесь не запускалась.
Пагинация по 12 записей сохраняет q и group. Нет цены — «Стоимость уточняется»;
цена 0 отображается, отрицательная цена отклоняется модельной/админ-валидацией.
Тексты экранируются Django, HTML из описаний не выполняется.

Общая шапка/подвал, подсказки site-action-help, поиск товаров в дополнительном
меню, личный кабинет и форма обратного звонка сохранены. Отдельного AJAX API
услуг пока нет. GET-поиск работает без JS. Ссылка вопроса ведёт на существующую
форму главной; название услуги предлагается указать в комментарии.

Миграция home.0010_clinic_service добавляет одну таблицу; старые таблицы
и строки не переименовываются, не удаляются и не исправляются.
До миграции нужен проверенный снимок базы через backup_db.py.
При откате после миграции сначала восстановите снимок, затем откатывайте
файлы. Установщик блокирует откат файлов, пока миграция 0010 отмечена в БД.
Восстановление снимка отменяет ВСЕ изменения БД после его создания.

Для страницы введён home/vet_base.html: общая оболочка внутренних страниц,
шапка/подвал и действующие подсказки. Стили адаптируются 3/2/1 колонками.
Исторический test_furniture_services.py обновлён под новое назначение того же
URL; проверки маршрута, навигации и sitemap сохранены.
