# Шаг 1. Название ветеринарной клиники в Django-админке

Проект: vet-asist.ru, репозиторий NetMann-git/django-vet-catalog-beget.
Проверенная исходная версия: 17463f6 (мебельный шаг 83).

Заменено название LUSTRID в заголовке вкладки и шапке Django-админки.
Убраны мебельный логотип и подключение мебельных favicon из шаблона админки.
Используется штатная адаптивная шапка Django, включая светлую и тёмную темы.
Права доступа, формы, модели, URL и данные не меняются. Миграции не нужны.
Логотип клиники пока не подключён; на этом шаге используется текстовое название.

## Найденная основа для следующих шагов

- config/settings/dev.py: SQLite из base.py, локальные адреса.
- config/settings/prod.py: MySQL, домены и секреты из окружения.
- apps/home/models.py: ContactSettings, TeamMember, ClientShowcase.
- apps/home/urls.py: управление контактами и командой.
- apps/appointments: существующие механизмы записи и обратной связи.
- apps/products, apps/reviews, apps/search: каталог, отзывы, поиск.
- config/urls.py: сохранены публичные и служебные маршруты.

Публичные шаблоны всё ещё содержат мебельные тексты, изображения и логотипы.
Это промежуточный этап; сайт ещё не готов к публикации как сайт клиники.
Контактные данные, услуги, цены, врачи, режим работы и юридические реквизиты
не следует заполнять вымышленными сведениями. База и медиа в Git отсутствуют:
их содержимое не изучено. Версия локального checkout пользователя неизвестна:
установщик проверяет исходный файл по содержимому с учётом CRLF/LF.

Дальше: адаптация публичной шапки с согласованным логотипом и названием,
затем главной страницы и существующей записи. Назначение каталога и набор
ветеринарных услуг требуют отдельного согласования.
