# Шаг 2 — общая оболочка ВетАссист

Шапка и подвал сведены к общим include-шаблонам для двух существовавших
вариантов оболочки. Маршруты, модели и формы сохранены. На компьютере основные
ссылки видны в строке, на телефоне — в раскрывающемся меню. Меню доступно
без JS; JS добавляет Escape, закрытие снаружи и учёт высоты липкой шапки.

Палитра: сливочный #faf8f3, лесной #294a3d, шалфей #eef2e8,
лавандовый #f2edf5, рыжий #bc8058. Интерфейс использует локальный Open Sans,
название в подвале — Georgia. Токены доступны для следующего этапа вёрстки.
Стили содержимого страниц пока не менялись.

Включён исходный PNG логотипа без изменения байтов, размера или качества.
Пропорции сохранены через height:auto; CSS уменьшает только отображение.
Старые favicon адаптируются отдельным шагом.

Дополнительное меню сохраняет каталог, сравнение, избранное, историю,
материалы, портфолио, личный кабинет и поиск. Используется существующий
search.js и его API. Поиск пока по каталогу, не по услугам клиники.

Телефон новой оболочки берётся только из явно заданного VET_CLINIC_PHONE
в Django settings. При отсутствии номера выводится ссылка «Контакты».
Значение не берётся из ContactSettings: миграция 0008 содержит контакты
другого проекта. Записи базы не изменяются: старое содержимое главной
и страницы контактов пока может их показывать. Перед публикацией эти
данные нужно заменить отдельным согласованным шагом.

Пока используется «Оставить заявку», переход на существующую форму #callback.
Это не готовая запись к ветеринару: тексты формы меняются позднее.
Пункт «Врачи» появится вместе с публичной страницей врачей.
Публичные страницы ещё содержат мебельный контент. Юридические страницы
и их тексты также требуют дальнейшей адаптации.

Миграции не требуются, база не изменяется. Шаг совместим с исходной версией
17463f6 и с установленным шагом 1: файл админки здесь не изменяется.
